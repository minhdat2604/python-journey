Hướng dẫn bắt đầu hành trình

Làm từng bước nhỏ. Hoàn thành bài trong VS Code trước, rồi quay lại đây đánh dấu những mục bạn đã tự chạy và kiểm tra.

1Mở đúng dự án

Mở thư mục gốc python-journey-main trong VS Code.

2Mở bài tập

Bắt đầu với ex01_variables.py; làm các TODO bắt buộc theo thứ tự.

3Chạy và thử

Lưu file, chạy bằng Python. Thử dữ liệu mẫu và tự giải thích kết quả.

4Chấm lại

Chạy máy chấm ở cuối trang. Đọc mục cần sửa, quay lại code rồi thử lần nữa.

Máy chấm code Python 🧪

Để chấm 10 TODO trong các file bài tập của bạn, chạy lệnh này trong Terminal tại thư mục gốc dự án:

py weeks/week-02-variables-types/assessment/core-exercises/student_journey.py --student

Nếu máy không nhận lệnh py, thay bằng python. Bộ chấm sẽ tạo báo cáo ở .learner-output/week02-journey.html. Chỉ chạy code do bạn viết hoặc tin cậy.

Các dấu chọn được lưu trong trình duyệt trên thiết bị này. Trang không gửi dữ liệu qua Internet.
